# 機械学習・化学シミュレーション 演習 一覧（C3）

各演習の問題文（課題）のみをまとめたREADMEです。
対応するコードは同名の `C3_enshuukadai_XX.py`（演習版）と
`C3_enshuukadai_XX_kaisetsu.py`（解説付き解答版）を参照してください。
演習版はTODOを埋める前でも最後まで実行できます（結果は仮の値になります）。

## C3_enshuukadai_01.py − 汚染物質の濃度と影響を分析する線形回帰モデル

汚染物質の濃度と、それによる影響（Effect）のデータから線形回帰モデルを
構築し、訓練・テストに分割したうえでMSEとR²で評価する。

## C3_enshuukadai_02.py − 教師なし学習によるワインのクラスタリング

ワインの13種類の化学的特徴量を用いて、KMeansで3つのクラスタに分類する。
正解ラベル（ワインの種類）はクラスタリングには使用しない。

## C3_enshuukadai_03.py − PCAによるワイン成分の次元削減

ワインの13種類の特徴量を標準化したうえでPCAにかけ、2つの主成分へ要約する。
主成分の寄与率と、ワインの種類ごとの分布を確認する。

## C3_enshuukadai_04.py − 反応物の濃度から反応速度を求める

化学反応 A + B → C の濃度の時系列データから、反応物・生成物それぞれの
濃度変化をプロットし、反応速度（Δ濃度／Δ時間）を計算する。

## C3_enshuukadai_05.py − 2次元ランダムウォークによる拡散のシミュレーション

1つの粒子が2次元平面上を上下左右へランダムに動くシミュレーションを行い、
Nステップ後の軌跡をプロットして拡散の概念を理解する。

## C3_enshuukadai_06.py − 温度と粒子サイズに依存するランダムウォーク

5番を拡張し、温度と粒子の大きさによってステップサイズが変わる
ランダムウォークを2種類の粒子（サイズの異なる2つ）についてシミュレートし、
拡散のしやすさの違いを比較する。

## C3_enshuukadai_07.py − ニューラルネットワークによる化学データのパターン認識

化合物の分子量・極性・水素結合ドナー数・アクセプター数から溶解度を予測する
ニューラルネットワーク（MLPRegressor）モデルを構築し、MSE・R²で評価する。

## C3_enshuukadai_08.py − 壁の振動データのフーリエ変換

壁A・壁Bの振動時系列データにフーリエ変換（FFT）を適用し、周波数スペクトル
を比較して、卓越する周波数成分の違いを確認する。

## C3_enshuukadai_09.py − ランダムフォレストによる新規材料の耐久度予測

材料A・B・Cの混合比率と各種物性から耐久性を予測するランダムフォレスト
モデルを構築し、耐久性を最大化する混合比率を最適化アルゴリズムで求める。

## C3_enshuukadai_10.py − ディープニューラルネットワークによる新規材料の耐久度予測

09番と同じデータを使い、ニューラルネットワーク（MLPRegressor）で
耐久性を予測するモデルを構築し、任意の混合比率から耐久度を予測する
関数を作成する。

### 解答版で行った主な修正

- **08番**：ファイル冒頭の課題文コメントが「7番：ニューラルネットワークに
  よる溶解度予測」のまま残っており、実際のコード（振動データのFFT解析）と
  内容が一致していなかったため、実際のコードに合わせて課題文を書き直しました。
- **01・02・03・07・08・09・10番**：CSVファイルが同梱されていなかったため、
  無い場合の模擬データ自動生成を追加しました。02・03番は、scikit-learn
  付属の本物のワインデータセット（`load_wine`）をフォールバックとして
  使用しています（03番では、元コードでimportされていたが未使用だった
  `load_wine`を実際に活用する形にしています）。
- **05・06番**：乱数のシードが固定されておらず毎回結果が変わっていたため、
  `np.random.default_rng(42)` を使うよう修正し、再現性を持たせました。
- **09番**：Random Forest（木構造）の予測を勾配ベースの最適化手法で扱う際の
  注意点（初期値から動きにくい場合がある）を追記しました。
