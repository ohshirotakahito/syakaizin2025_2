# pandas・NumPy基礎 演習 一覧（B1）

各演習の問題文（想定する場面・課題）のみをまとめたREADMEです。
対応するコードは同名の `B1_enshuukadai_XX.py` を参照してください。

## B1_enshuukadai_01.py − 10店舗の販売数をNumPy配列で扱う

10店舗を展開するチェーン店で、各店舗の本日の販売数が集計された。
1. 店舗番号（1～10）をNumPy配列として作る。
2. 各店舗の販売数をNumPy配列として作る。
3. 全店の合計販売数と、平均販売数を求めて表示する。

## B1_enshuukadai_02.py − 研修参加者名簿をDataFrameで作る

社内研修の参加者について、氏名・所属部署・研修の得点を1つの表として
まとめて管理したい。
1. 参加者の氏名、所属部署、得点をまとめたDataFrame（表形式のデータ）を作る。
2. 作成した表と、表が持つ列名の一覧を表示する。

## B1_enshuukadai_03.py − 品質検査CSVを安全に読み込む

品質検査で測定した吸光度データ（CSVファイル）を読み込んで分析したい。
ファイルが手元にない環境でも演習を進められるようにする。
1. 読み込みたいCSVファイルの場所（パス）を作る。
2. ファイルが存在するか確認し、存在しなければデモ用のCSVを作成する。
3. CSVファイルをpandasで読み込み、先頭数行・行数・列数・列名を表示する。

## B1_enshuukadai_04.py − 検査データへ判定列を追加しCSVへ出力する

品質検査の測定値（吸光度）について、「平均以上かどうか」を一目で
分かるようにしたい。
1. 検査データのCSVを読み込む（なければデモ用データを作る）。
2. 数値列の平均値を求め、各行がその平均以上かどうかを判定する列を追加する。
3. 判定を追加した表を、新しいCSVファイルとして保存する。

## B1_enshuukadai_05.py − 発注点以下の在庫商品を抽出する

在庫管理で、在庫数が発注点（追加発注の目安）以下になっている商品を
自動的に見つけ出したい。
1. 商品名、在庫数、発注点を持つ表（DataFrame）を作る。
2. 在庫数が発注点以下の商品だけを抽出して表示する。

## B1_enshuukadai_06.py − 配送依頼を締切の早い順に並べる

配送センターに届いた複数の配送依頼を、優先度を最優先にしつつ、
同じ優先度の中では締切が早いものから処理できる順に並べ替えたい。
1. 依頼ID、締切時刻、優先度を持つ表（DataFrame）を作る。
2. 優先度→締切時刻の順で、依頼を並べ替えて表示する。

## B1_enshuukadai_07.py − 配送時間の代表値を集計する

配送にかかった時間（分）の記録の中に、渋滞などで大きく時間がかかった
特別なケースが含まれている。平均だけでなく中央値も確認したい。
1. 配送時間の記録を持つ表（DataFrame）を作る。
2. 平均・中央値・最大値をそれぞれ求めて表示する。
3. 極端な値（外れ値）が結果に与える影響について考える。

## B1_enshuukadai_08.py − 欠測した温度センサー値を補完する

温度センサーの記録の一部が通信不良などで欠測してしまった。
欠測値を「もっともらしい値」で埋めたい。
1. 温度の記録（一部欠測あり）を持つ表（DataFrame）を作る。
2. 欠測している値の数を確認する。
3. 欠測値を、記録全体の中央値で埋める。

## B1_enshuukadai_09.py − 売上表へ客単価を追加し、一時列を削除する

店舗ごとの売上金額と来店客数のデータから「客単価」を計算したい。
外部報告用には来店客数の列を取り除いた表を作る。
1. 店舗名、売上金額、来店客数を持つ表（DataFrame）を作る。
2. 売上金額 ÷ 来店客数で「客単価」の列を追加する。
3. 外部報告用に、来店客数の列を取り除いた表を作る。

## B1_enshuukadai_10.py − 東西2拠点の研修名簿を縦に結合する

東日本拠点と西日本拠点で別々に作っていた研修参加者名簿を、
全社集計のために1つの表にまとめたい。
1. 東日本拠点の参加者名簿（DataFrame）を作り、拠点名の列を追加する。
2. 西日本拠点の参加者名簿（DataFrame）を作り、拠点名の列を追加する。
3. 2つの表を縦に結合し、1つの表として表示する。
