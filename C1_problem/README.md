# 基本計算・検量線 演習 一覧（C1）

各演習の問題文（想定する場面・課題）のみをまとめたREADMEです。
対応するコードは同名の `C1_enshuukadai_XX.py`（演習版）と
`C1_enshuukadai_XX_kaisetsu.py`（解説付き解答版）を参照してください。

## C1_enshuukadai_01.py − 検査サービスの請求額を基本演算で計算する

検査会社が複数の検体をまとめて依頼してきた顧客へ請求書を発行する。
1. 単価と検体数から小計を計算する。
2. 小計から値引き額を引き、値引後の金額を求める。
3. 値引後の金額に消費税をかけ、税額を求める。
4. 値引後の金額と税額を足して、最終的な請求額を求める。

## C1_enshuukadai_02.py − 倉庫内の直線距離と保管容量を計算する

倉庫内の2つの作業地点間の移動距離の目安と、棚全体の最大保管数を求めたい。
1. 水平方向・垂直方向の距離から、三平方の定理を使って直線距離を求める。
2. 棚の段数と1段あたりの箱数から、棚全体の最大保管数を求める。

## C1_enshuukadai_03.py − 標準液の濃度と吸光度を可視化する

分析装置の検量線を作るため、標準液の濃度と吸光度の関係を確認したい。
1. 標準液の濃度と、それぞれの吸光度をNumPy配列として用意する。
2. 濃度と吸光度の相関係数を計算する。
3. 濃度と吸光度の関係を散布図で可視化する。

## C1_enshuukadai_04.py − 吸光度の検量線から未知試料濃度を推定する

既知濃度の標準液から作った検量線を使い、濃度が分からない未知試料の
吸光度から濃度を逆算して推定したい。
1. 標準液の濃度と吸光度から、線形回帰で検量線（直線の式）を求める。
2. 求めた検量線の式を、切片と傾きの形で表示する。
3. 未知試料の吸光度から、検量線の式を逆算して濃度を推定する。
4. 標準液・検量線・推定した未知試料の点をグラフに表示する。

## C1_enshuukadai_05.py − 原液を希釈して作業用試薬を調製する

濃度の分かっている原液を水で薄めて、作業用試薬を作りたい。
1. 原液の体積と加える水の体積から、最終的な液量を求める。
2. 原液の濃度・体積と最終液量から、希釈後の最終濃度を求める。
3. 最終液量が原液の体積の何倍かを表す希釈倍率を求める。
